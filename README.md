# Psychology 101 Interactive Mind Map 🧠

A comprehensive, interactive mind map web application designed for undergraduate Psychology 101 students. This study tool covers all major topics typically found in a one-semester introductory psychology course.

## 📚 Features

### Interactive Learning
- **Expandable Topic Cards**: Click on any topic to reveal subtopics
- **Detailed Content Panels**: Click on subtopics to view comprehensive information including:
  - Overview descriptions
  - Key points for each concept
  - Important terms and vocabulary
- **Progress Tracking**: Double-click topics to mark them as studied
- **Search Functionality**: Quickly find any concept, term, or topic (Ctrl+K)

### Design
- 🌙 Dark/Light theme toggle
- 🎨 Beautiful gradient color palette for each topic
- ✨ Smooth animations and micro-interactions
- 📱 Fully responsive design

## 🎓 Course Topics Covered

1. **Introduction to Psychology** - History, Methods & Perspectives
2. **Biological Psychology** - Brain, Neurons & Nervous System
3. **Sensation & Perception** - How We Experience the World
4. **Consciousness** - Sleep, Dreams & Altered States
5. **Learning** - Classical, Operant & Observational
6. **Memory** - Encoding, Storage & Retrieval
7. **Cognition & Intelligence** - Thinking, Language & Problem-Solving
8. **Human Development** - Lifespan Growth & Change
9. **Motivation & Emotion** - What Drives Our Behavior
10. **Personality** - Individual Differences & Traits
11. **Social Psychology** - How Others Influence Us
12. **Psychological Disorders** - Understanding Mental Health
13. **Therapy & Treatment** - Approaches to Healing

Each topic contains 4-7 subtopics with detailed explanations, covering **60+ concepts** essential for introductory psychology.

## 🚀 Getting Started

### Run Locally

1. Clone this repository
2. Open the folder in your terminal
3. Start a local server:
   ```bash
   npx serve
   ```
4. Open http://localhost:3000 in your browser

### Or Simply Open

Just open `index.html` directly in your browser!

## 💡 How to Use

1. **Browse Topics**: Scroll through the colorful topic cards
2. **Expand**: Click any topic card to see its subtopics
3. **Learn**: Click a subtopic to open the detail panel with key information
4. **Track Progress**: Double-click a topic card to mark it as "studied" (shows a ✓ checkmark)
5. **Search**: Use the search bar to quickly find any term or concept
6. **Theme**: Toggle between light and dark mode using the button in the header
